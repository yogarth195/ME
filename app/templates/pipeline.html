How ExplainHire Works

A 7-layer hybrid pipeline — symbolic reasoning meets neural AI

L1
📄 Input Validation
Accepts PDF or DOCX resume + raw JD text. Checks file type and size (<5MB).
PDF DOCX pdfplumber python-docx
L2
🔍 Parse
Extracts skills, years of experience, education level, and section structure from both resume and JD.
Skill extractor JD parser regex section detection
→ skills[], YOE, education, sections{}
L3
🌐 Skill Ontology
A 434-node knowledge graph of tech skills with parent-child relationships. Built from O*NET occupational database. Understands that PyTorch → deep_learning → machine_learning.
434 skill nodes O*NET data NetworkX DiGraph CHILD_OF edges IS_ALIAS_OF edges
→ graph ready for matching
3 Independent Signals
△ Graph Score
Ontology-based skill matching. 6 match levels from exact (1.0) to no match (0.0). Symbolic AI.
graph_score ∈ [0, 1]
◆ SBERT Score
Neural sentence embeddings. Measures overall semantic similarity between resume and JD text.
sbert_score ∈ [0, 1]
■ Structural Score
Rule-based. Scores YOE gap, education gap, and presence of key resume sections.
structural_score ∈ [0, 1]
L5
🤖 XGBoost Classifier
Fuses all 14 features from L4 into a final match/no-match prediction. Trained on 967 real + synthetic resume-JD pairs. SHAP explains which feature drove the score.
XGBoost SHAP 14 features 967 training rows CV F1 = 0.803
→ label (0/1) + probability + shap_values[]
L6
💡 Explain
Evidence mapper finds exact sentences in the resume proving each matched skill. Skill gap analyzer greedily adds missing skills until the match threshold is crossed.
Evidence mapper Skill gap analysis sentence matching greedy threshold
→ evidence{skill: [sentences]}, gap_skills[]
L7
🌐 Present
Flask UI renders verdict banner, 3 score cards, SHAP reasons, skill breakdown with evidence, skill gap, and learning resource suggestions.
Flask 3.x Jinja2 dark/light theme drag-drop upload
L1
Input Validation
pdfplumber · python-docx

Validates uploaded file is PDF or DOCX and under 5MB. Extracts raw text using pdfplumber for PDFs and python-docx for Word files.

Supported: .pdf · .docx · .doc  |  Max 5 MB
L2
Parse
regex · section detection · JD parser

Splits resume into sections (Experience, Education, Skills, Projects) using heading detection. Extracts YOE from date ranges, education level from degree names, and skill list from all sections with confidence weights.

Section confidence: Experience 1.0 → Projects 0.9 → Skills 0.8 → Education 0.5
L3
Skill Ontology
NetworkX DiGraph · O*NET 30.2

A directed knowledge graph where edges encode skill relationships. Two edge types: CHILD_OF (skill is a subtype of another) and IS_ALIAS_OF (alternate name for the same skill).

Built from our manual taxonomy + O*NET Technology Skills database filtered to hot/in-demand tech occupations.

L4
Match — 3 Independent Signals
Graph matcher · SBERT all-MiniLM-L6-v2 · Structural scorer

Signal 1 — Graph Score

For each JD skill, traverses the ontology to find the best match in the resume. 6 directional levels:

Match typeScoreExample
Exact1.0python = python
Alias0.9js = javascript
Child→Parent0.7pytorch → ML
Parent→Child0.5ML → pytorch
Sibling0.4pytorch ~ tensorflow
2-hop ancestor0.3pytorch → AI
No match0.0python vs swift

Signal 2 — SBERT Score

Encodes resume text and JD text into 384-dimension vectors using all-MiniLM-L6-v2. Cosine similarity gives a score from 0 to 1. Captures semantic meaning beyond keywords — "developed APIs" matches "REST API experience".

Signal 3 — Structural Score

Rule-based scoring of: YOE gap (0yr→1.0, 3yr+→0.1), education gap (same→1.0, 2 levels below→0.2), section completeness (4 key sections). Weighted 40%/30%/30%.

L5
XGBoost Classifier
XGBoost · SHAP TreeExplainer

Takes 14 numeric features from L4 and predicts match probability. Trained with 5-fold stratified cross-validation. SHAP assigns each feature a contribution score for every prediction.

L6
Explain
Evidence mapper · Skill gap engine

Evidence mapper: For each matched skill, scans resume sentences for the skill name and its variants (nodejs → "node.js", cicd → "ci/cd"). Returns up to 2 evidence sentences per skill.

Skill gap analysis: Greedily adds the highest-impact missing skills until the predicted graph_score crosses 0.7. Assigns learning resources with priority ranking.

Priority 1: missing skills  ·  P2: parent→child gaps  ·  P3: sibling gaps
